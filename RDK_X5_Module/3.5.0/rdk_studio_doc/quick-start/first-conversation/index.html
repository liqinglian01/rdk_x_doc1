调起 AI Dock ​ AI Dock 是屏幕底部常驻的对话区，可以直接点击底部输入框激活

第一条消息 ​ 在输入框中输入： 帮我查看这台设备的系统概况 按回车发送

Studio 会执行以下步骤： 把消息发送给当前激活的 Thinking 车道模型 模型理解意图后，自动调用设备工具（通过 SSH 在板端执行命令） 几秒内返回当前激活设备的硬件指标：CPU、内存、磁盘、镜像版本、关键服务状态 整个过程中，Agent 调用的命令会在远程终端中实时显示，方便开发者了解 AI 在做什么
