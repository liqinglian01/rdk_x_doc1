Studio 会自动探测可写路径（如 ~/openclaw 、 /userdata/openclaw ）

如果探测错误，在 OpenClaw 面板 → 部署设置 中手动指定可写目录

板端 Node 版本 SSH 进板端执行 node --version 确认版本 ≥ 18
