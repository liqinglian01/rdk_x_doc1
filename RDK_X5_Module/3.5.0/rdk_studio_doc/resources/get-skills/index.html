本节描述四种获取路径及相关决策点

四种获取路径 ​ 全部入口都在 技能工坊

路径 1：内置技能中心（最快） ​ 技能工坊 → 技能中心 → catalog → 浏览 D-Robotics 出品的官方技能目录（45+ 个）

按分类组织： 核心操作（core/）：设备诊断、硬件知识、OpenClaw 协作 板型专属（boards/）：RDK X5 应用、X5 AI 检测 文档与搜索（docs/）：RDK 官方文档、TROS 文档 通用工具（tools/）：浏览器自动化、搜索引擎 可选扩展（optional/）：Token 用量报告等 点击 安装到本地 或 部署到板端 即可

路径 2：ClawHub 社区搜索 ​ 技能工坊 → 技能中心 → ClawHub 社区 → 输入关键词搜索： 操作 怎么做 关键词搜索 顶部搜索框 预览技能 点技能名 → 看 SKILL.md 全文与 frontmatter 一键安装 安装到本地 或 部署到板端 批量安装 勾选多个技能 → 批量装 ClawHub 默认走国内镜像

如果搜不到目标，确认网络可达 ClawHub 域名

路径 3：从 URL 导入 ​ 把任意外部内容转化为技能： URL 类型 自动识别规则 GitHub 仓库 URL 含 github.com/... NodeHub 案例 URL 含 developer.d-robotics.cc/nodehub 普通网页 / 博客 默认 操作步骤： 技能工坊 → 技能中心 → 链接 粘贴 URL，Studio 自动识别来源 填写目标描述："我想让 AI 学会 X" 选择适用设备型号（X3 / X5 / S100 / 通用） AI 自动抓取并转化为 SKILL.md 预览 → 调整 → 安装 路径 4：手动放文件 ​ 最低门槛——同事或群里发来一个 SKILL.md： 保存到本机工作区 skills/<name>/SKILL.md Studio 自动扫描发现，无需重启 在 已安装 列表能看到它 安装位置的选择 ​ 选项 装到哪 谁能用 安装到本地 Studio 进程内 PC 端 D-Moss Agent 部署到板端 通过 OpenClaw 同步到板端 OpenClaw 工作区 板端 Agent 如果希望板端常驻 Agent 也能使用该技能（例如长期监控、断网自治）， 必须选择"部署到板端"

仅安装到本地的技能板端 Agent 看不到

装多少合适 ​ 数量 影响 小于 10 无感 10~30 AI 选技能耗时增加（毫秒级） 大于 50 上下文膨胀，AI 决策可能受干扰 不要"装一堆备用"

用什么装什么，没用就在 已安装 列表卸载

验证已装的技能 ​ AI Dock 中输入 /skills → 列出当前会话注入的技能 ID 与简要说明

注入是按需动态加载的——不是所有装过的技能都同时在上下文

/skills 显示的是"目前这个会话已激活的"

让 AI 帮你找技能 ​ 不知道哪个技能能解决你的问题

直接对 AI Dock 说"有没有让我能调试 USB 摄像头的技能

" Agent 会在内置目录和 ClawHub 里搜索，列出几个候选并简要说明各自的能力，你选一个让它装上

常见获取问题 ​ 现象 解决 ClawHub 搜索无结果 换更通用的关键词；确认网络可达 ClawHub 域名 URL 导入失败 URL 不可达、内容太长、格式不识别；可手工转 SKILL.md 走路径 4 装上后 AI 没使用 检查 SKILL.md 的 trigger 与你的实际场景是否匹配；必要时修改 trigger 后重启 Studio 技能太多导致 AI 决策乱 卸载不用的技能，见 3.11.5 触发匹配机制 的优化建议 最后 于 2026年4月30日 更新 上一页 4.1 技能分享 下一页 4.3 NodeHub 案例 四种获取路径 路径 1：内置技能中心（最快） 路径 2：ClawHub 社区搜索 路径 3：从 URL 导入 路径 4：手动放文件 安装位置的选择 装多少合适 验证已装的技能 让 AI 帮你找技能 常见获取问题 友情链接 古月居 联系我们 GitHub BiLiBiLi Copyright © 2026 D-Robotics.
