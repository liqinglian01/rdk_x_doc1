示例简介​

本项目包含多个基于 Python 编写的 BPU 使用示例程序，适用于 RDK X5 （软件版本 3.5.0）平台，覆盖图像分类、目标检测、实例分割、姿态估计等常见任务。示例使用 .bin 格式的量化模型进行推理，便于开发者快速验证模型效果并开展应用开发。

本项目的板端代码位置：/app/pydev_demo/
