📄️ 2.3 config.txt 文件配置

RDK 使用配置文件config.txt来设置一些启动时候的系统配置。config.txt 会在uboot阶段被读取，支持修改设备树的配置，IO管脚状态，ION内存，CPU频率等。该文件通常可以从 Linux 访问/boot/config.txt，并且必须以root用户身份进行编辑。如果在config.txt配置设置，但是该文件还不存在，只需将其创建为新的文本文件即可。
