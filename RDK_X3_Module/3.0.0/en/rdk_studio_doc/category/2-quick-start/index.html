📄️ 2.2 烧录系统镜像 板端没有可用系统、系统损坏或需要更换镜像时，从这一步开始

🗃️ 2.3 接入设备 3 个项目 📄️ 2.4 配置网络 为板端配置 WiFi 连接，让板可以独立接入网络

本节给出最简的接入方式；详细的模型条目字段、双车道路由机制、协议判定规则在 3.12 配置中心 详细说明
